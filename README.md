
# BÀI 2: TẠO HTTP SERVER BẰNG NODE.JS

## 1. Thông tin sinh viên

- Họ tên: Đỗ Trung Ngọc Bảo
- Lớp: CD-CNTT18A
- Môn học: Node.js
- Bài thực hành: Bài 2

## 2. Yêu cầu bài thực hành

- Tạo HTTP Server bằng Node.js thuần.
- Chạy server tại cổng 3000.
- Truy cập http://localhost:3000.
- Trả về trang HTML có tên sinh viên.
- Đưa mã nguồn lên GitHub.

## 3. Công cụ sử dụng

- Node.js
- Visual Studio Code
- Google Chrome

## 4. Mã nguồn

Chương trình được viết trong file `server.js`.

Sử dụng module `http` có sẵn trong Node.js
để tạo HTTP Server.

Server lắng nghe tại cổng 3000 và trả về
nội dung HTML chứa thông tin sinh viên.

## 5. Hướng dẫn chạy chương trình

Mở Terminal tại thư mục Bai02_NodeJS.

Chạy lệnh:

    node server.js

Mở trình duyệt và truy cập:

http://localhost:3000

## 6. Kết quả thực hiện

- HTTP Server khởi động thành công.
- Truy cập được localhost:3000.
- Trang HTML hiển thị họ tên sinh viên.
- Chương trình đáp ứng yêu cầu bài thực hành.
